# 2700 Dover Street — public home vision

This repository contains only public listing photographs, illustrative home-design concepts, and the concept video. Inspection reports, contracts, attorney correspondence, appraisal, insurance, and personal notes are intentionally excluded and remain in a separate private repository.

All concept images are planning illustrations. Verify measurements, structure, utilities, permits, plant safety, and animal-welfare requirements before work.

## Furniture planning

`furniture-data.json` records confirmed purchases, shared references, room assignments and measurement provenance. Use `null` for unknown dimensions. A generated picture or a shared seller photo does not establish ownership or measured fit; change those fields only from the user's confirmation.

The currently confirmed items are the TV console (exact photo and measurements unresolved), the dark desk holding the monitors, and the narrow oak glass-door bookcase. The pale 61-inch L-shaped desk is a reference, not the confirmed desk. The orange sofa is still under consideration.

`furniture-checks.js` evaluates an entered rectangular envelope, operating allowances, duplicates and an entered budget. It does not reconstruct doors, heater zones, L-shaped cutouts or delivery turns. Passing its dimension check is not a purchase approval.

Draft reviews and optional draft photos stay in the visitor's browser. The static site does not receive them. Export the review and share it in chat to update the published inventory. Keep original family photographs, handwritten journal pages and private documents outside this public repository; the public desk reference is an explicitly labeled generated furniture-only illustration.
